## Extracting Information With LLM and RAG from scratch and using langchain

<details>
<summary> Extracting Text Information with LLM and RAG from scratch </summary>

## Project Overview:

One of the bottlenecks in a data pipeline is extracting trustworthy and accurate information from various sources.With the help of LLMs, data extraction can make it easier to populate a scalable data pipeline.In this project, sample text documents are used to implement a basic RAG pipeline. The system retrieves relevant text chunks to provide Llama 3.2 with context for answering user queries.In this project, a basic RAG pipeline is implemented from scratch using Python 3.12.


🏗️ System Architecture:

- Text is split into chunks of 8 words, with an overlap of 3 words between consecutive chunks.
- Each text chunk is converted into a vector embedding using the nomic-embed-text model through Ollama.
- Qdrant is used as a vector database to store chunk embeddings and their associated text and metadata for similarity search.
- The user's query is converted into an embedding question using the `nomic-embed-text` model.
- Similarity search is performed by Qdrant using cosine similarity. Higher similarity scores indicate that the retrieved vectors are more similar to the query vector.
- The context is constructed from the text content of the points retrieved from Qdrant.
- The answer is generated by Llama 3.2 through Ollama. A prompt is constructed using the retrieved text context and the user's query, and then passed to the model to generate a response.

🚀 Quick Start:
1. Install the Python dependencies
uv add ollama qdrant-client
2. Install Docker Desktop
Install and start Docker Desktop
3. Run Qdrant
docker run -d --name qdrant -p 6333:6333  qdrant/qdran
4. Run the application
uv run python main.py

<summary> Extracting PDFs Information with LLM and RAG using LangChain </summary>

## Project Overview:

One of the bottlenecks in a data pipeline is extracting trustworthy and accurate information from various sources.With the help of LLMs, data extraction can make it easier to populate a scalable data pipeline.In this project, sample pdfs are used to implement a basic RAG pipeline using Langchain. The system retrieves relevant information from pdf for user's query.


🏗️ System Architecture:

- Document Ingestion: PDF files are loaded using LangChain's native PyPDFLoader configured in page mode, where each page is mapped to an independent Document object.
- Text Segmentation: The extracted text is processed and segmented using the RecursiveCharacterTextSplitter based on predefined chunk size and overlap parameters.
- Vectorization: Embeddings are generated seamlessly by instantiating the OllamaEmbeddings class utilizing the nomic-embed-text model
-Vector Storage & Indexing: The Qdrant vector database is integrated for storing and indexing vector representations. LangChain abstracts away the underlying boilerplate (such as point structuring, IDs, and payload management), handling data insertion automatically via QdrantVectorStore.from_documents.
- Semantic Retrieval: Relevant context is fetched from the vector store by executing the similarity_search method against the user's query vector.
- Augmented Generation: The retrieved context and user query are synthesized into a prompt, and the llama3.2 model is leveraged for accurate, context-aware response generation.

</details>
